# Task: встроить loader «Отпечаток FINCODE» в кабинеты

Референс (ветка `main`): https://github.com/AntonMinich/loader-

Один визуал — градиентный отпечаток из логотипа и скан по гребням. Меняется только текст и логика фраз.

| Вариант | Кабинет | Репозиторий |
| --- | --- | --- |
| **1 · B2C** | клиентский кабинет | `fincode-web` |
| **1.2 · B2B** | кабинет партнёра | `fincode-web-partners` |
| **1.3 · Админка** | админ-панель | `fincode-web-partners-admin` |

Варианты «Сканер документов» и «Волна графика» в эту задачу **не входят**.

## Когда показывать

Полноэкранный (или на весь рабочий холст кабинета) оверлей ожидания при любом ожидании ответа бэкенда, пока пользователь не может продолжить:

- вход («Войти»);
- отправка заявки / формы;
- загрузка и проверка документов;
- расчёт / сохранение / смена статуса, если экран блокируется до ответа.

Не показывать кнопку «Закрыть превью» — это только для демо. Скрывать loader, когда запрос завершился (успех или ошибка). Не закрывать по клику на фон.

## Общий визуал (все три кабинета)

Взять из референса:

- `img/fingerprint.svg` — знак, градиент `#5281F3` → `#01F69B`;
- `img/fingerprint-mask.svg` — альфа-маска, чтобы скан шёл только по гребням;
- стили `.fc-print`, `.fc-print__mark`, `.fc-print__scan`, `.fc-loader`, `.fc-overlay` из `css/styles.css`.

Правила:

- подложка под отпечатком не нужна (без квадрата, ореола, drop-shadow);
- светлая карточка лоадера на полупрозрачном оверлее **или** тёмный оверлей с белым текстом — как принято в конкретном кабинете, знак остаётся градиентным;
- `role="status"`, `aria-live="polite"`, `aria-busy="true"` на время показа;
- при `prefers-reduced-motion: reduce` остановить пульс и скан.

## 1 · B2C → `fincode-web`

Заголовок: **Секунда пользы**

Под заголовком — ротация фактов, **не** статусы сервера («загрузка…», «проверяем…»).

Интервал смены: **3 секунды**.

При **каждом** появлении лоадера первая фраза **случайная**, не одна и та же заготовка. Дальше идти по перемешанному набору без повторов, пока набор не кончится; затем перемешать снова. Не показывать подряд одну и ту же фразу.

Набор (точки в конце фраз сохраняем):

1. Лизинг не замораживает всю сумму: покупка уже у вас, деньги остаются в обороте.
2. Наличными вы платите 100% сразу. В лизинге — аванс, остальное удобными платежами.
3. Пока копите наличными, цена может вырасти. Лизинг фиксирует условия сегодня.
4. Лизинг — это способ распределить расходы во времени без необходимости копить всю сумму сразу.
5. Финансовые цели достигаются быстрее, когда есть чёткий план платежей.
6. Фиксированный платёж проще планировать, чем откладывать нужную покупку.

Логика: `js/app.js` (`cycleFacts`, `FACT_INTERVAL_MS = 3000`). Не копировать демо-кнопку закрытия.

## 1.2 · B2B → `fincode-web-partners`

Тот же отпечаток, **без** ротации.

> Пара секунд —

Одна статичная фраза на всё время ожидания.

## 1.3 · Админка → `fincode-web-partners-admin`

Тот же отпечаток, **без** ротации.

Текст **ровно** (без точки в конце):

> Проверяем всё,  
> чтобы лизинг шёл как по маслу

Одна статичная фраза на всё время ожидания.

## Критерии приёмки

- В `fincode-web` при ожидании API виден вариант **1**: заголовок «Секунда пользы», факты меняются каждые 3 с, первая фраза при повторном открытии не всегда одна и та же.
- В `fincode-web-partners` — вариант **1.2**, только фраза про «Пара секунд…», без точки, без фактов B2C.
- В `fincode-web-partners-admin` — вариант **1.3**, только фраза про «Проверяем всё…», без точки, без фактов B2C.
- Отпечаток совпадает с референсом (официальный SVG, скан по гребням, без подложки).
- Loader исчезает после ответа сервера; пользователь не может «закрыть превью» руками.
- Спиннер/старый индикатор на тех же экранах заменён, а не дублируется.

## Вне скоупа

- Сканер документов и волна графика.
- Изменение бэкенд-контрактов.
- Показ лоадера на мгновенных клиентских переходах без ожидания сети.
