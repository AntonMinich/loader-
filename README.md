# FINCODE loaders

Страница с индикаторами загрузки в стиле лизинговой компании FINCODE.

## Варианты

1. **Кольцо FINCODE** — универсальный loader с отпечатком из логотипа. Вместо статусов сервера показывает факты, почему лизинг выгоднее оплаты наличными.
2. **Сканер документов** — отдельный сценарий для загрузки и формирования пакета файлов.
3. **Этапы сделки** — длинная операция с обратной связью по шагам.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 4173
```

Затем откройте http://127.0.0.1:4173
