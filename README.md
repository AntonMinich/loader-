# FINCODE loaders

Страница с индикаторами загрузки в стиле лизинговой компании FINCODE.

## Варианты

1. **Отпечаток FINCODE** — универсальный loader: градиентный отпечаток из логотипа и факты, почему лизинг выгоднее оплаты наличными.
2. **Сканер документов** — загрузка и формирование пакета файлов.
3. **Волна графика** — ритм платежей для подбора срока и ежемесячной суммы.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 4173
```

Затем откройте http://127.0.0.1:4173
