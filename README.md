# FINCODE loaders

Страница с тремя вариантами индикаторов загрузки в стиле лизинговой компании FINCODE (палитра и типографика публичного сайта и кабинета партнёра).

## Варианты

1. **Кольцо FINCODE** — короткое ожидание ответа API.
2. **Сканер документов** — загрузка, проверка и формирование пакета файлов.
3. **Этапы сделки** — длинная операция с обратной связью по шагам.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 4173
```

Затем откройте http://127.0.0.1:4173
